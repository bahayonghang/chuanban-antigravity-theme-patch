# 技术设计

## 边界

最小行为缺口是默认亮色没有接管真实 .agy-shell/.agy-sheet 表面，以及过重的共享线条与桃粉输入框令牌。样式所有者为 core/theme.css；只改该文件和生成的 core/manifest.json。用户已请求继续原内核优化任务。

## CSS 策略

新增亮色 high-contrast 与历史别名范围，使用 :not([data-ag-scheme="dark"]) 阻断暗色泄漏；不修改现有暗色块、共享阴影、发送按钮或其它预设令牌。预设基础变量在 html 和 body.theme-light 两层保持一致，避免 body 自有变量遮挡。新增 --ag-* 默认值不加 !important，继续允许根节点行内 themeVars 覆盖。表面规则只接管已确认的真实容器，去除冷蓝顶光，不增加 DOM 或轮询。

## 兼容与回退

保留所有历史别名和蜡封状态选择器。不改配置格式。部署使用 install.mjs install，已有 user/ 无损保留；不修改安装器。对照验证采用暂时替换样式和 data 属性，finally 恢复，不保存 scheme/preset。若完整验收未通过，任务保持进行中，不归档。

## 设计取舍

暖墨 15% 用于表面分隔，不是文字对比度目标；弱化文字单独检查 4.5:1。保留原发送按钮和暗色阴影以保证范围。色值是基于官方品牌参考的本项目设计，不宣称官方桌面令牌。
